# Architecture
- Keep the Pedido workflow client-only and read-only against AppContext; planning purchases must never create stock movements or modify existing inventory workflows.
- Keep Pedido calculations and export generation in dedicated modules so existing forecast and report calculations remain untouched.
- Persist non-editable Pedido snapshots in a dedicated order_history table through an isolated module; never write inventory data, enforce existing center assignments with RLS, and allow individual deletion only through a Master-only database policy after UI confirmation. The application uses external production, so activation SQL must be supplied for that database rather than applied to the unrelated managed database.
